# v0.1.0 — 全市场组合回测 MVP

- **状态**：已发布（历史基线）
- **时间范围**：约 2026-05-06 ~ 2026-05-30
- **摘要**：本地 DuckDB 行情库、Universe 过滤、组合引擎、组合 API、投资治理与多策略分配、前端组合模式。

## 主要能力

- `backend/marketdata` — 行情仓库、刷新脚本、Universe
- `backend/portfolio` — 组合引擎、Broker、动量 TopK / ETF 轮动
- `POST /api/backtest/portfolio`、`/api/backtest/portfolio/multi`
- 前端：组合回测、治理 Tab、决策审计、多策略分配
- 性能：5000 标的 × 5 年基准约 8s（universe SQL 下推、动量矩阵等）
