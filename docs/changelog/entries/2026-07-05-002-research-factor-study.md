| **均值回归主导** | ret_20 Rank IC = -0.033, rsi_inv Rank IC = +0.046 | 短期超买会跌，超卖会涨 |
| **趋势跟随式微** | golden_cross Rank IC = -0.021 | 金叉买入在过去半年亏钱 |

| **长期动量失控** | mom_250 Rank IC = -0.020 | 涨了一年的股票反而在回调 |

### 🏆 最优策略：多因子集成

**构成**：Golden Cross + RSI反转 + MACD + 250日动量 + BB反转 + 成交量收缩 + 20日收益率 + 连续性

**原理**：
- 单一因子信号噪音大，集成后平滑信号
- 各因子捕捉不同维度的信息（趋势/反转/质量/量价）
- 等权平均，简单鲁棒

**绩效**（Top 20% vs Bottom 20% 多空组合）：
- 周均收益差：+0.61%
- 年化约 +31%（未扣成本）
- 胜率：59%
- 连续周数稳定

### ⚠️ 重要警告

1. **Rank IC 不直接反映赚钱能力**！Reversal 组合的 IC 最高（+0.046）但实际亏钱
2. **当前市场是均值回归主导**，不适合趋势追踪策略
3. **金叉（Golden Cross）在过去半年失效**，可能需要市场回到趋势状态才有效
4. **因子方向会变化**：同样的因子在不同市场环境下表现相反

## 因子分类体系

### 按时间维度

| 类别 | 因子 | 持有期 | 调仓频率 |
|------|------|--------|---------|
| **短线** | RSI反转、BB位置、成交量收缩 | 1-5天 | 每周 |
| **中线** | 20日动量、MACD、连续性 | 5-30天 | 每2周 |
| **长线** | Golden Cross、250日动量 | 30+天 | 每月 |

### 按因子类型

| 类型 | 因子 | 逻辑 |
|------|------|------|
| **趋势** | Golden Cross, MACD, 250d动量 | 跟随价格方向 |
| **均值回归** | RSI反转, BB反转, 20日反转 | 逆势交易 |
| **质量** | 连续性、稳定性 | 选优质股票 |
| **量价** | 成交量收缩、量价相关性 | 资金面信号 |

### 按市场

| 市场 | 因子 |
|------|------|
| **CN 专属** | ST过滤、涨跌停概率、行业轮动 |
| **US 专属** | VIX波动率、行业ETF轮动、标普500偏离 |
| **通用** | 所有动量/反转/技术因子 |

## 实际投资建议

基于当前市场环境（2026年7月）：

1. **重视均值回归**：超买股票要警惕回调
2. **谨慎追趋势**：不要追高金叉信号
3. **多因子过滤**：单一信号不可靠，需要多因子确认
4. **缩量是机会**：成交量缩小表明筹码稳定，后续容易上涨
5. **避开放量股**：换手率急剧放大的股票后续表现差
