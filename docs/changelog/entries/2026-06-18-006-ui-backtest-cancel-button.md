# [ui] 回测运行中可取消（停止回测）

- **日期**：2026-06-18
- **版本**：v0.2.0（未发布）
- **类型**：ui

## 变更

- 「运行回测」旁新增红色「停止回测」按钮，运行中显示
- 使用 `AbortController` 中断 fetch：单股、组合、多策略、自定义 Python 回测
- 取消后提示「回测已取消」；K 线二次请求同样绑定 signal

## 相关文件

- `frontend/index.html`

## 验证

1. 启动组合回测 → 点击「停止回测」
2. 进度停止、按钮恢复，不出现未捕获异常

## 说明

取消为客户端中断；服务端长任务可能仍会继续计算直至连接关闭。
