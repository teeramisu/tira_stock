## 技术栈

- **深度学习**: PyTorch 2.8 + CUDA, Transformer Encoder (d=48, heads=4, layers=2)
- **数据存储**: DuckDB (行情), JSON (lifecycle/hypotheses/reports), PT (模型权重)
- **特征工程**: 10维市场特征 (breadth_ma60/ma20, trend_20d/5d, crash_5d, vol, vol_of_vol, momentum_disp, volume_trend, breadth_mom)
- **训练策略**: Expanding window + early stopping + cosine annealing + gradient clipping
